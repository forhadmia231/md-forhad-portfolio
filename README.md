## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/forhadmia231/md-forhad-portfolio.git
```

Go to the project directory:

```bash
cd md-forhad-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```
